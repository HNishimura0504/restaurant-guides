# 要件定義書 — 端末に応じた2パターン表示（PC/タブレット と スマホ）

- 起案: 2026-09-19
- ユーザー依頼（原文）: 「**閲覧してるデバイスがpc/タブレットかスマホかを判別して、pc/タブレットモードとスマホモード2パターンで表示されるようにできる？**」
- 状態: **確定・実装済み**（2026-09-19）。方式・対象・一覧の形はいずれも本人が「推奨」を選択。

---

## 1. 現状（すべて実測。推測ではない）

Chromium の端末エミュレーション（iPhone 相当 390×844・`isMobile:true`／PC 1280×800）で
実際に開いて測った値。

| ページ | viewport メタ | `@media` | スマホでのレイアウト幅 | 横はみ出し |
|---|---|---|---|---|
| **ガイド記事 66本** | **0 / 66 本** | **0 / 66 本** | **980px**（画面は390px） | なし（縮小されるため） |
| 地図 `map/*.html` 67本 | あり | **なし** | 390px | なし |
| 都市一覧 `index.html` | あり | **なし** | 390px | なし |

### 1-1. 記事の問題は「縮小」— これが最大の実害

**`<meta name="viewport">` が1本も無い。** その場合、スマホのブラウザは
**仮想的に 980px の画面として描画し、実機の幅に合わせて縮小する**（390/980 ＝ **40%**）。

記事の本文は `font-size:10.5pt`、目次の項目はさらに小さい。
**40%に縮められると、目次の項目は実質 3〜4px になり、拡大しないと読めない。**
スクリーンショットで確認済み（見出しは辛うじて読めるが、店名の行は潰れている）。

**＝記事側は「2パターンにする」以前に、スマホで実用になっていない。**

### 1-2. 地図・一覧の問題は「形が変わらない」

`viewport` メタは入っているので**縮小はされず、横はみ出しも 0**。
ただし `@media` が1本も無いため、**PC用の形のまま縮むだけ**。実測:

- スマホ（390×844）で **ヘッダ 105px ＋ カテゴリのチップ 134px ＝ 239px**（画面の **28%**）を
  固定で占め、地図に残るのは 605px。
- 一覧の表は 366px に収まっており、**横スクロールは起きていない**。
- ポップアップは `width:250px` の決め打ち。

**＝地図側は「壊れてはいないが、スマホ向けに最適化されていない」。**

### 1-3. 紙面用の体裁が同居している

記事66本は **`@page{size:120mm 240mm}` を全本持つ**（印刷・PDF化を想定した作り）。
**この体裁を壊さないことが制約になる。**

## 2. 方式の選択肢

### A. レスポンシブ（CSS の `@media` で画面幅により切り替える）

- HTML は1本。**幅という観測可能な量**で切り替える。
- 回転・画面分割・ウィンドウのリサイズにその場で追従する。
- 新しいガイドを足しても、スタイルを共有していれば自動で効く。

### B. UA（User-Agent）判定で、PC用とスマホ用の2種類のHTMLを出し分ける

- **端末の判別が当たらない。** とくに **iPadOS の Safari は既定で「デスクトップ用サイト」を
  名乗り、UA が Macintosh になる**ので、**タブレットとPCを UA で分けることは原理的にできない**。
- **ページ数が 133 → 266 になる。** 記事66本は生成物ではなく**個別に書かれたHTML**なので、
  二重管理になる（片方だけ直す事故が確実に起きる）。
- GitHub Pages は静的配信なので、**サーバ側で振り分けられない**。
  JavaScript でリダイレクトすることになり、初回表示が一瞬ちらつく。

### C. A ＋ 手動の切替ボタン（推奨）

- **実体は A（幅で切り替える）**。そのうえで画面に
  **「PC表示 / スマホ表示」の切替**を置き、選択を `localStorage` に覚える。
- **自動判定が外れたときの逃げ道**になる（大きいタブレットで「スマホ表示」が欲しい、
  小さいノートPCで「PC表示」を固定したい、等）。
- ユーザー依頼の「**2パターンで表示**」を、文字どおり**利用者が選べる形**で満たす。

### 比較

| 観点 | A レスポンシブ | B UA判定で2種類 | **C A＋手動切替** |
|---|---|---|---|
| 端末判別の正しさ | 幅で判定＝**当たる** | **iPad が PC を名乗るので当たらない** | 幅＋利用者の意思 |
| ファイル数 | 133 のまま | **266 に倍増** | 133 のまま |
| 回転・画面分割 | 追従する | 追従しない | 追従する |
| 新規ガイドの追加 | 自動で効く | **2本書く必要** | 自動で効く |
| 「2パターン」の明示性 | 暗黙 | 明示 | **明示（ボタンがある）** |

**推奨 = C。** 判定は当たる方法（幅）で行い、外れたときの逃げ道を利用者に渡す。

## 3. 変更の範囲（案）

### 3-1. ガイド記事 66本（実害が大きい方）

1. **`<meta name="viewport" content="width=device-width, initial-scale=1">` を追加**（1行／本）。
   **これだけで縮小が止まり、実寸で読めるようになる。**
2. スマホ幅（`max-width: 640px`）用の `@media` を追加:
   - 本文・目次の文字サイズを実効 14px 以上に
   - 目次の2段組みを1段に
   - 左右の余白を詰める（紙面用の `@page` は**触らない**）
3. `notion/add_sitenav.py` と同じ方式（**各記事のCSSに依存しない自前の `<style>` を差し込む**）で、
   **冪等なスクリプト**として実装する。

### 3-2. 地図ページ 67本 ＋ 都市一覧

1. スマホ幅で**ヘッダとチップの占有を減らす**（チップを横スクロールの1行にする等）。
2. ポップアップの `width:250px` を**画面幅に追従**させる。
3. 一覧をスマホでは**カード型**にする（表の列が窮屈なため）。
4. `build_map.py` の `CSS` に `@media` を足す＝**1か所直せば67本に効く**。

### 3-3. 切替ボタン（方式Cを採る場合）

- 置き場所: 記事は先頭の行き来の帯（`gnav`）、地図はヘッダ。
- 既定は「自動」。押すと「PC表示」「スマホ表示」に固定し、`localStorage` に保存する。

| # | 条件 | 測り方 |

## 6. 実装（2026-09-19）

- `notion/rwd.py` … 共有部品。`dual()` がスマホ用の規則を
  **`@media screen and (max-width:640px){ html:not(.vm-pc) … }`** と
  **`@media screen{ html.vm-phone … }`** の2か所へ展開する。
  **`screen` を必ず付ける**＝付けないと `@page{size:120mm}`（≒453px）の**印刷にも当たる**。
- `notion/add_responsive.py` … 記事66本へ `viewport` メタ・スマホ用の規則・切替ボタンを差し込む（冪等）。
- `notion/build_map.py` … 地図と都市一覧の CSS に同じ仕組みを足す（**1か所直せば67本に効く**）。

**切替の3状態**（`localStorage` に記憶）:

| モード | viewport | スマホ用のCSS |
|---|---|---|
| 自動（既定） | `width=device-width` | 画面幅 640px 以下で当たる |
| スマホ表示 | `width=device-width` | 幅に関係なく当たる |
| PC表示 | **`width=1100`** | 当たらない |

## 7. 受入条件の実測結果（2026-09-19）

| # | 条件 | 結果 |
|---|---|---|
| 1 | 390px 幅で横スクロールが発生しない | **134ページ中 0件** |
| 2 | 記事の本文の実効文字サイズが 14px 以上 | **134ページ中 13.5px未満 0件**（記事の本文 15.3px・説明 14.7px） |
| 3 | 1280px での見た目が現状と変わらない | `index` / 地図 / 記事とも**はみ出し0・一覧は `table-row` のまま** |
| 4 | 印刷の体裁が壊れない | 同じ453px幅で **screen＝1段・15.3px／print＝2段・14px**（＝元の値）。切替ボタンは印刷で `display:none` |
| 5 | リンク切れ 0 | 記事リンク3,586本・写真3,763枚・行き来132本とも **0** |
| 6 | 切替が両方向に効く | 自動→スマホ(`vm-phone`)→PC(`vm-pc`・`width=1100`・表に戻る)→自動。**再読み込み後も保持** |

**副次的な効果**: スマホでヘッダ＋チップが占める高さが **239px → 132px（45%減）** になり、
地図に使える高さが 605px → 712px に増えた。
