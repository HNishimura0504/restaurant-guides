# 要件定義書 — Notion版 美食ガイドに「目次」と「店舗マップ」を付ける

- 起票: 2026-09-02
- 対象リポジトリ: `HNishimura0504/restaurant-guides`
- 対象ブランチ: `claude/notion-toc-restaurant-map-2529rf`
- 変更するもの: `notion/build_md.py`・`notion/sync.py`・`.github/workflows/notion-sync.yml`
- ユーザー依頼（原文）: 「Notionの記事だけど、目次みたいなの付けられない？あとレストランガイドに地図つけて欲しい」

## 0. 現状（実測）

| 項目 | 実測値 |
|---|---|
| Notion 成果物DB に本文化済みのガイド | 55冊（`notion/map.tsv`・`notion/state/upload_state.json`） |
| 1冊の構成 | 見出し2（ジャンル）6個前後 ＋ 見出し3（店名）40〜70個 |
| 目次 | **無い**。ページ先頭は「導入文 → タグの意味 → 区切り線 → ジャンル見出し」 |
| 地図 | **無い**。`build_md.py` が本文冒頭に「元PDFの店舗マップ画像は取り込んでいません」と明記して除外している |
| 地図画像の実体 | `<地方>/<国 or 県>/img/<市>/_map.png`（全域）と `_map2.png`（中心部拡大）。**47冊にあり、欧州8冊（ブリュッセル・リエージュ・ルーベン・ヘント・パリ・アムステルダム・ケルン・フランクフルト）には無い** |
| 地図画像の量 | 95枚・合計177.4MB・最大5.25MB（`japan/tokyo/img/tokyo23/_map2.png`）・寸法は概ね 900〜1800px 四方 |

## 1. 目的

Notion 上の記事だけで「①目当ての店へ飛べる ②店の位置関係が分かる」状態にする。
HTML版・PDF版は既に両方を持っており、Notion版だけが欠けている。

## 2. 要件

### F-1 目次

- **F-1-1** 各ガイドページの本文冒頭（導入文とタグ説明の直後、最初のジャンル見出しの前）に目次を置く。
- **F-1-2** 目次の各行はタップで該当箇所へジャンプできること。
- **F-1-3** 目次は本文の見出しから自動生成されること（店の追加・改名で手直しが要らないこと）。
- **F-1-4** 目次の粒度と畳み方は §4 の決定事項に従う。

### F-2 店舗マップ

- **F-2-1** 目次の直後・最初のジャンル見出しの前に「🗾 店舗マップ」の節を置き、全域マップと中心部拡大マップの2枚を貼る。
- **F-2-2** 見出し文言は HTML の `.mapttl` から取るが、Notion では画像のピンをタップできないため
  「（ピンをタップで各店のページへ）」は落とし、代わりに注記を1行置く。
  注記＝「ピンの色はカテゴリ見出しの色に対応。番号は掲載順（各カードの番号バッジと一致）。
  Notion版ではピンをタップできません。位置は各店の『地図』リンクから。地図: © OpenStreetMap contributors」
- **F-2-3** 本文冒頭の「元PDFの店舗マップ画像は取り込んでいません」という文言を、地図を載せた旨に書き換える。
- **F-2-4** 地図画像はアップロード前に**長辺1600pxのJPEG（品質85）へ縮小**する。
  理由＝最大5.25MBのPNGがあり、Notion のファイルサイズ上限（無料プランは1ファイル5MB）に触れるため。
  縮小はワークフロー内で行い、リポジトリ内の元PNGは変更しない。
- **F-2-5** 地図画像が無い欧州8冊は、地図の節そのものを出さない（他は従来どおり）。

### F-3 再同期

- **F-3-1** 変更は各ガイドの part01 に入るため、**55ページすべてを本文から書き直す**。
  `notion/state/upload_state.json` の `written_parts` を空にして全パートを再生成する。
- **F-3-2** 店の写真2,901枚は `uploads` に file_upload_id が残っているので**再アップロードしない**。
  今回新規に上がるのは地図94枚（欧州8冊ぶんを除く）のみ。
- **F-3-3** ルーベンのページには店舗DBの子データベースがあるが、`clear_page` が子DB・子ページを残す実装済みのため壊れない。

## 3. 非要件（今回やらないこと）

- 欧州8冊への地図画像の新規生成（別途 `map_build.py` での作図が必要）。
- Notion 上での地図ピンのタップ移動（Notion は画像内リンクに対応しないため実現できない）。
- HTML版・PDF版の変更（既に目次・マップを持っている）。

## 4. 決定が要る事項（ユーザー確認）

| # | 論点 | 選択肢 | 当方の推奨 |
|---|---|---|---|
| Q1 | 目次の粒度 | (a) 全店（ジャンル＋店名の2階層・40〜70行） / (b) ジャンルのみ（6行） | **(a)**。店名から飛べることが目次の主目的のため |
| Q2 | 目次の畳み方 | (a) トグルに入れて既定は畳む / (b) 開いたまま置く | **(a)**。全店だと先頭が長くなるため |
| Q3 | 地図が無い欧州8冊 | (a) 今回は対象外 / (b) 地図も作る | **(a)**。作図は別作業で規模が違うため |

- 本番実行後、代表1冊（吹田）を Notion API で読み直し、目次ブロックと地図画像2枚が入っていることを確認する。
- ルーベンのページの子データベースが残っていることを確認する。
