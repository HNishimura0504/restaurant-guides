## 2. 章の構成

**岡山市は8章**。寿司・和食／洋食・デミカツ丼・えびめし／中華そば・ラーメン／うどん・そば・お好み焼き・町中華／居酒屋・郷土料理・地酒／焼肉・ホルモン／イタリアン・フレンチ・各国料理／喫茶・カフェ・フルーツパーラー・甘味。

**既存の章の色は6色しか無かったので、章を圧縮せず `build_html.py` と `map_build.py` に2色を足した**（`brown` `#8a5a2b`／`green` `#3f7d20`。既存6色と彩度・明度の系統をそろえてある）。既存の冊には影響しない。**広島市・福岡市など今後の政令指定都市でも同じ必要が出るので、この2色を使い回すこと。**

**倉敷市は6章**。寿司・和食・瀬戸内の魚／うどん・そば・お好み焼き／ラーメン・中華そば／居酒屋・郷土料理・地酒／洋食・デミカツ丼・えびめし／喫茶・カフェ・甘味。

## 6. 写真

候補は**岡山市522本・倉敷市313本**。そこから**全数を目で見て**1店1枚を選定。

採用の出どころ:

- 岡山市 … ホットペッパー36／岡山観光WEB18／各店の公式サイト7／おかやま観光コンベンション協会5／ぐるなび3／岡山県郷土文化財団1／地球の歩き方1／岡山スタイル1
- 倉敷市 … ホットペッパー30／各店の公式サイト7／KCTトクもりっ6／岡山観光WEB4／倉敷観光WEB2／個人ブログ1

**目視で外したもの**: 人物が主役の写真（廣榮堂 中納言本店の店内の物販棚・橘香堂の従業員と来店客・麒麟閣の店員2名・喫茶 エル・グレコの来店客5名・調理人が大きく写ったもの数点）、値段が書かれた黒板やポスター、外観だけの写真、ロゴ板、ほぼ同一の重複（画像の平均ハッシュで先に洗ってから目で確認）。

**除外の理由は4つだけ**（playbook と同じ）: ①食べログ ②媒体名・番組名の透かしが焼き込まれているもの ③AI生成イラスト ④その店と無関係の写真。**「無断転載禁止」の表示は除外の理由にならない**（AI_memory.md §4[2026-07-10]）。**写真の大きさの下限は「長辺900px以上」**（短辺は問わない。B-698）。

### 次に使える取得先（この回で見つけたもの）

- **倉敷市公式観光サイトの WordPress REST API**: `https://www.kurashiki-tabi.jp/wp-json/wp/v2/eat?per_page=100&_fields=id,link,title`（`&search=<語>` で絞り込み可）。画像は `https://www.kurashiki-tabi.jp/wp-content/themes/kurashiki/images/map-list/eat/<投稿ID>/001.jpg` を**直接叩く**（002、003…と続く）。**このパスはページのHTMLに出てこない。** 最大 6720×4480 の実例あり。ただし投稿IDが1000番台の古い掲載は 280×210 しか無い。
- **ホットペッパーの写真ギャラリー**: `https://www.hotpepper.jp/<strJ…>/photo/`。その店自身のギャラリーだけが取れて全店共通の広告画像（`P04616xxxx` 系）が混ざらない。URLのサイズ接尾辞（`_480` 等）を削ると 1280px の原寸。
- **岡山県観光連盟「おか旅」の記事内画像**: `https://www.okayama-kanko.jp/lsc/upfile/blogDetail/0002/<4桁>/<5桁>_<n>_l.jpg` で 1400〜2000px。**画像の持ち主はHTMLの出現順で決まるので、ファイル名でソートすると別の店の写真を掴む。**
- **おかやま観光コンベンション協会**（`okayama-kanko.net`）: `-1024x683` などの接尾辞を削ると原寸（最大6000×4000）。

### 落とし穴

- **ホットペッパーで掲載契約の無い店（Alike提供の情報だけの店）の `/photo/` には、他店の画像しか並ばない。** alt属性に店名が入っているかで切り分けられる。この回で実際に3店（ONSAYA COFFEE 問屋町店・ホンキートンク・cafe モン・ルポ）が引っかかった。
- 「フルーツパフェの街おかやま」公式（`okayama-parfait.com`）は住所・電話・営業時間が正確で新しいが、**画像は最大526×450**で全部が下限割れ。情報源としては優秀、写真源としては使えない。

## 7. 写真が薄い店（下限の3本に届かなかったもの）

## 9. 出典が食い違っていて、両論を `reason` に残したもの

- 名代とんかつ かっぱ（倉敷市）… 営業時間・定休日が3通り。3つのうち2つが一致する「月・火休」を採った。
- 喫茶 エル・グレコ（倉敷市）… 5つの出典が 10:00〜17:00 で一致し、倉敷観光コンベンションビューローの会員ページだけ 11:30〜16:00。前者を採った。
- 名もなき天ぷら酒場（倉敷市）／Ikiya（岡山市）／せんべや（倉敷市）／だてそば（岡山市）／岡山浜作（岡山市）… いずれも更新の新しい側を採り、食い違いを明記。

## 10. 申し送り

- **ダルマ 浜店**（岡山市・焼肉）のホットペッパー掲載ページが貼っている `yakinikudaruma.com` は、**兵庫県揖保郡太子町の別の「焼肉だるま」**。`website` は空のままにしてある。
- **児島（倉敷市）は洋食・喫茶でゼロ**。写真の条件を満たす店が見つからなかった。居酒屋の串なごみと麺のお好美屋で児島を拾っている。
- **問屋町（岡山市）は和食・麺でゼロ**。ホットペッパーのフリーワード検索で該当が出なかった。居酒屋のネオとよじ、各国料理の Rock DoG と韓国食堂ゆぱ、喫茶の faim de loup で拾っている。
- つけ麺の専門店は岡山市に1店も入っていない（候補のつけめん烏城は掲載が2020年1月で現況を確認できず）。
