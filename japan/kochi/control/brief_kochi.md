# 共通の決まり（必ず全部守る）

## 出力
- 結果は **1つの JSON 配列**として、指定のファイルパスへ `Write` で書く（他の場所へ書かない）。
- 配列の各要素は次のキーをすべて持つ。**値を推測で埋めない。確認できないキーは空文字にして `reason` にその旨を書く。**

```
{
 "id": "<city>-<category>-<ローマ字の短い識別子>",   // 例 kochi-kyodo-hirome-myojin。半角小文字とハイフンのみ
 "name": "店名（正式表記）",
 "yomi": "ひらがなの読み",
 "category": "<このエージェントの担当カテゴリのキー>",
 "short": "20字程度の一言",
 "genre": "居酒屋 / 郷土料理 / ラーメン などのジャンル名",
 "price": "代表的な品の価格を3つ程度。末尾に「（出典名 2026-11-10 取得）」",
 "area": "最寄り駅・電停からの徒歩分数や道順、駐車場の有無",
 "desc": "150〜350字。席数・支払い方法・予約の要否・創業・成り立ち・混む時間など、行く前に知りたい実務情報。**主観の形容詞を並べない。**",
 "sig": "名物料理を2〜3品。各品に括弧で中身の説明",
 "reason": "この章に入れる理由と、**営業の根拠（下の営業確認を満たした証拠を日付つきで書く）**",
 "tags": ["official"],            // 下の「タグ」を見る
 "hours": "営業時間（曜日で違うなら曜日ごと）",
 "closed": "定休日",
 "address": "高知県から始まる完全な住所",
 "phone": "0888-xx-xxxx",         // **数字・ハイフン・括弧・+・空白のみ。注記を書かない（注記は desc へ）**
 "website": "公式サイトのURL（無ければ空文字）",
 "resv": "予約の可否と方法",
 "sources": [ {"label": "<何が確認できるか>（<日付>）2026-11-10 取得", "url": "https://..."} ],
 "photo_urls": [ "料理・店内の実写画像の直URL", ... ],   // 3〜10本。無ければ [] と reason に理由
 "ext_urls":   [ "店の外観（建物の正面・入口・店構え）の実写画像の直URL", ... ]  // 1〜4本。無ければ [] と理由
}
```

## 営業確認（**2つとも満たした店だけ採用する**）
1. **店が自分で出した 2025〜2026 年の情報を1つ以上**（公式サイトの更新・公式SNSの投稿・お知らせ欄の日付）。**日付を書く。**
   第三者の掲載ページの状態（**ネット予約カレンダーが先の日付まで空いている・口コミ件数・掲載が残っている**）は1を満たさない。
2. **閉店していないことの確認を3通り**
   ① `<店名> 閉店` を**空白を入れた形と詰めた形の両方**で検索
   ② **公式SNSのアカウント名そのものを読む**（投稿の中身ではなく名前。「旧〇〇／現在は△△」に変わっていることがある）
   ③ `<店名> 移転`・`<店名> リニューアル` でも1回ずつ
   営業の根拠が開店の告知記事だけの店は、とくに念入りに。
**1つでも欠けたら採用しない。** 店数が足りなくなっても、確認できない店で埋めない（足りない数を報告する）。

## 写真の出どころ（印刷して配る成果物なので保守的に取る）
**使ってよい**
- 店自身（公式サイト・公式SNS・公式が配る素材）
- 公式の観光協会・商店街・自治体のサイト
- **編集部が取材して載せている地域の媒体**
- **ホットペッパーグルメの掲載写真**（`imgfp.hotp.jp`）。ただし `data-genre="post"` の**利用者の投稿写真は不可**

**使わない（1本も入れない）**
- 利用者の投稿写真を集めた場＝**食べログ**（`tabelog.com` / `tblg.k-img.com`）・**Retty**・じゃらんの口コミ・**miil**
- **個人ブログ**（アメブロ・livedoor Blog・はてな等。撮影者が店でも媒体でもない）
- **媒体名の透かしが焼き込まれたサイト**
- **`*.goguynet.jp`（号外NET）**＝利用規約で転載禁止（2026-11-08 に確認済み）
- **`miton-imabari.jp`（みとん今治）**＝利用規約 第5条で転載禁止

**透かしの確認は必ず実物を切り出して目で見る。** 「たぶん無い」と書かない。
```bash
curl -sL -A "Mozilla/5.0" "<画像URL>" -o /tmp/x.jpg
python3 -c "
from PIL import Image
im=Image.open('/tmp/x.jpg'); w,h=im.size; print(im.size)
im.crop((int(w*0.40),int(h*0.70),w,h)).save('/tmp/corner.png')"
```
そのうえで `/tmp/corner.png` を `Read` ツールで開いて見る。透かしがあれば、そのホストの画像は**全部**捨てて `reason` に書く。

**ロゴ・バナー・地図画像・メニュー表の写真・クーポン画像は入れない。** 幅400px未満の画像も入れない。
**人の顔が写っている客の記念写真は入れない。**

## タグ
`"official"`＝公式サイトで確認した／`"hotpepper"`＝ホットペッパーグルメの掲載で確認した／
`"rinsetsu"`＝**担当都市の外（隣接市）の店**（担当が南国市のときだけ使う。香南市・香美市・いの町・土佐市の店に必ず付ける）。

## 使わない道具
Google Maps Platform（Places API・Place Photos）は使わない。鍵が無い。座標も取らない（親が国土地理院で解く）。

## やってはいけないこと
- 同じ店を2回入れない。**住所と電話が同じなら同じ店**。
- チェーン店の全国どこにでもある店舗を埋め草に入れない（その土地の名物を出す店・その土地で長く続く店を優先）。
- 価格・営業時間を「だいたい」で書かない。出典に書いてある値をそのまま写す。
- **報告を返す前に、必ず JSON ファイルを書く。** 最後の返答には「書いたファイルのパス・採用した店数・落とした店とその理由・写真が0本だった店」を箇条書きで書く。
