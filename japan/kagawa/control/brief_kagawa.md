## 3. 営業している根拠（`reason` に必ず書く）

次のどれかを、**日付つきで**書いてください。

1. 公式サイト・公式SNSの**2025〜2026年の更新**（投稿日・更新日を書く）
2. ホットペッパーのネット予約カレンダーが先の日付まで「即予約可」になっている（確認した期間を書く）
3. 口コミの最近の日付（Yahoo!マップ等。日付を書く）

**【重要】根拠が「開店の告知記事」だけの店は、`店名 + 閉店` で1回検索し、閉店の報が無いことを確かめてから採用してください。** 開店記事は開店日の証拠であって、今日営業している証拠ではありません（実例＝開店3か月で閉じた店が2件あり、どちらも載せかけました）。

**グルメサイトに掲載が残っていることは、営業の証拠になりません。**

## 4. 写真の条件（ここを外すと作り直しになります）

- **大きさの下限＝長辺900px以上。**「長辺」です。短辺は問いません。
  - 合格の例: 1200×800・2880×800・1060×600・1280×853
  - 不合格の例: 640×480・699×446・825×550
- **食べログ（`tabelog.com` / `tblg.k-img.com`）は使わない。** 利用者の投稿写真なので転載できません。
- **媒体名の透かし（ウォーターマーク）が焼き込まれた画像は使わない。** 透かしは「1枚の事情」ではなく「配信元の方針」なので、1枚見つけたらそのサイト全体を避けてください。
  **「たぶん無い」で済ませず、実際に右下を切り出して目で見てください**:

```bash
curl -sL -A "Mozilla/5.0" "<画像URL>" -o /tmp/x.jpg
python3 -c "
from PIL import Image
im=Image.open('/tmp/x.jpg'); w,h=im.size; print(im.size)
im.crop((int(w*0.40),int(h*0.70),w,h)).save('/tmp/corner.png')"
```

そのうえで `/tmp/corner.png` を Read ツールで開いて目で見る。

- **写真が1枚も取れない店は採用しないでください。**（カードが作れません）

## 5. URL の扱い

- `website` と `sources[].url` は、**実際に開いたページの URL をそのまま**書く。
  **店名のローマ字からドメインを推測しない**（過去に3件とも誤り、別会社・存在しないドメイン・別県の旅館に当たりました）。
- ホットペッパーの画像は `https://imgfp.hotp.jp/<以下は店ごとに違う>` の形です（URL-CHECK-SKIP＝雛形）。`_480` を外すと大きくなることがありますが、**必ず大きさを測って確かめてください**（外しても変わらない場合があります）。

```bash
python3 -c "
from PIL import Image; import io, urllib.request
r=urllib.request.Request('<URL>', headers={'User-Agent':'Mozilla/5.0'})
print(Image.open(io.BytesIO(urllib.request.urlopen(r).read())).size)"
```

- 契約していない店のページの `/photo/` には**他店の写真が混ざります。** `alt` 属性を見て店名が一致することを確かめてください。

## 7. 【徳島県（2026-10-31）で実測した取得経路・香川でもまず試すもの】

### 写真源の歩留まり

1. **ホットペッパーグルメ**。徳島では1位だった（山口県とは逆の結論）。
   **画像URLの `_NNN` サフィックスを外した裸のURLが原寸（954〜1280px）を返す。** `_690`/`_820`/`_1000`/`_1280` はすべて404なので、**裸にするのが唯一の手**。
   別経路の原寸URLは `imgfp.hotp.jp/IMGH/<P番号の末尾4桁を2桁ずつ>/<P番号>/<P番号>.jpg`（scheme を付けて組み立てる。**先頭4桁ではなく末尾4桁**。例 `P043922396` → `/IMGH/23/96/…`）。
   **ただし非契約の基本掲載では裸URLが404で `_480` しか無い店が混ざり、原寸自体が 680〜855px しかない店もある**ので、1枚ずつ実測する。
   `/photo/` の `<li class="photo-list" …>` は**属性が改行をまたぐ**ので `re.DOTALL` 付きで取る。`data-genre` に `food`/`drink`/`appearance`/`other` のほか **`post`（利用者投稿・`images.miil.me`）が混ざるので除外**する。
   **電話番号は `https://www.hotpepper.jp/<店ID>/tel/` に平文で入っている**（店舗ページ本体はJSで隠している）。
2. **地元のタウン情報媒体**。徳島では `awawa.app`（本文の画像は `sumahononakani.com/tjn/upload/img_reports/detail/<64桁>.jpg`・一律1200px・透かし無し）。
   **記事の1枚目（アイキャッチ）には媒体名やシリーズ名の文字が焼き込まれているので必ず捨てる。** 本文中の写真は無印。
3. **県・市の公式観光サイト、観光協会、商店街の公式**。
4. **店の公式サイト**。原寸の取り方＝Jimdo（`image.jimcdn.com`）は `/transf/<何か>/` を `/transf/none/` に置換、グーペ（`r.goope.jp`）はサムネイルの `_l` を外す、Wix（`static.wixstatic.com`）は変換パラメータを削る。
5. **楽天ぐるなび**は山口では1位だったが、**徳島では検索も店舗ページも 503 で全滅**した。香川では1枚試してから判断する。

### 写真源として使ってはいけないもの

1. **食べログ**（利用者の投稿写真）
2. **個人ブログ**（アメブロ `stat.ameba.jp`・ライブドア等。撮影者が店でも媒体でもない）
3. **透かしの焼き込まれたサイト**

**よいもの＝店・公式の観光／商店街／自治体のサイト・編集部のある媒体。**
予約サービス（AutoReserve 等）は店舗提供写真だが、同じ店に編集部のある媒体の写真があるならそちらを採る。

### 徳島で使えなかった経路（香川でも同じ可能性が高い）

ヒトサラ（403）／AutoReserve（Cloudflare 403）／Retty（406）／まっぷる（画像が640×480固定）。
**県の公式観光サイトは情報源としては強いが、画像が 850〜860px 止まりで写真の条件（長辺900px以上）を満たさないことが多い。** 1枚測ってから使う。

### 座標が町名どまりのときの逃げ道

**Yahoo!マップの店舗ページから拾えます**（`toLat=`／`toLon=`）。デスクトップのUAが要ります。

```
curl -sL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64)" "https://map.yahoo.co.jp/v3/place/<店のID>" -o /tmp/m.html   # URL-CHECK-SKIP（雛形。<店のID> は検索結果から拾う）
```
既定で落ちるもの: ①`-A` を付けないと携帯向けの版が返り座標が本文に出ない ②`-L` を付けないと 301 で止まる ③本文の `&` は `&amp;` の実体参照。

### 営業の確認は3通り取る

**予約サイト・掲載サイトが生きていることは、店が開いていることの根拠になりません。**（掲載は閉店後も消えるまで残る）
①空白ありなしの両方で `店名 閉店` を検索 ②**公式SNSのアカウント名そのもの**を見る（閉店した店は「旧〇〇／現在は△△」に変える）③移転・リニューアルの検索。
**食べログに【閉店】と出ていても、それが支店のほうであることがある。** どの店舗の閉店なのか住所と電話番号で確かめる。

### データの食い違い（徳島で実際に踏んだもの）

- タウン情報媒体の店舗データの**電話番号が誤っている**ことがある（市外局番で突き合わせる）。
- **じゃらんの検索スニペットは信用しない。** 近隣店の口コミが混入して「閉店予定」などの文面が別店に付く。必ず当該ページ本文を開く。
- 古い公式サイトと新しい掲載で**営業時間が食い違う**ことがある。更新の新しいほうを採り、その旨を `reason` に書く。

## 8. 香川県の下調べ（これを前提に探してください）

### 高松市（人口 40.5万・約50店）

香川県の県庁所在地で、四国の玄関口。高松港（サンポート）からフェリーで小豆島・直島へ渡る。

- **讃岐うどん**＝この県の主役。**釜揚げ・ぶっかけ・かけ・しょうゆうどん・釜玉**が基本形。
  **セルフの店**（自分で湯がいて天ぷらを取る）が多く、**昼だけ・麺が終わり次第閉店**の店が少なくない。
  製麺所が店を兼ねている形（**製麺所型**）もある。高松市内では**木太町・香西・牟礼・国分寺**あたりに名店が散る。
- **骨付鳥（ほねつきどり）**＝**丸亀市が発祥**だが高松にも専門店がある。**親鳥（かたくて噛みごたえがある）**と**ひな鳥（やわらかい）**の2種。
- **瀬戸内の魚**＝**ハマチ**（養殖の発祥が香川。**オリーブハマチ**はオリーブの葉を餌に混ぜたブランド）、**サワラ**（春。刺身と押し抜き寿司）、**タコ**、**いりこ**（伊吹島産がうどん出汁の基本）、**穴子**。
- **オリーブ牛・オリーブ夢豚・さぬきコーチン**＝県のブランド。
- **しょうゆ豆**（そら豆を炒って醤油だれに漬ける常備菜）、**あんもち雑煮**（白味噌の雑煮に餡入りの餅）、**かっしゃ焼き**。
- **和三盆**（東かがわ市）、**灸まん**（琴平）、**おいり**（丸亀・坂出の嫁入り菓子）。
- **場所のかたまり**: ①**高松駅・サンポート**（朝うどんと海の見える店） ②**丸亀町商店街・兵庫町・片原町**（日本一長いアーケードの一帯） ③**瓦町・ライオン通り・古馬場（ふるばば）**＝高松最大の歓楽街。夜の店はここに集中 ④**栗林公園（りつりんこうえん）まわり** ⑤**屋島・牟礼・庵治（あじ）**＝東の郊外。石の町と海 ⑥**木太町・太田・レインボーロード**＝南の郊外。車で行くうどん店が多い。

### 丸亀市（人口 10.6万・約45店）

丸亀城（石垣の高さが日本一）の城下町。うちわの生産が全国の9割。

- **骨付鳥の発祥の地。** 市内に専門店が複数あり、**この章を独立させる**ほど厚い。
- **讃岐うどん**＝市内と、隣の**綾歌町・飯山町**に製麺所型の店が多い。
- **瀬戸内の魚**＝丸亀港・本島（ほんじま）。
- **場所のかたまり**: ①**丸亀駅前・通町商店街** ②**丸亀城の南（大手町・一番丁）** ③**土器町（どきちょう）・川西**＝国道11号沿いの郊外 ④**綾歌町・飯山町**＝南の旧町 ⑤**本島・広島**＝塩飽（しわく）諸島。
- **人口10.6万で店の総数が少ないので、隣接市町で補ってよい。** 補った店には JSON に `"tags": ["rinsetsu"]` を入れ、`desc` の冒頭に「（坂出市）」のように市町名を書く。
  補ってよいのは **坂出市・善通寺市・宇多津町・多度津町・琴平町・綾川町・まんのう町**。
