### 島根県で効いた経路
- ホットペッパー＝**島根県 `SA72` / 松江 `Y955` / 出雲市 `Y956`**。
  フリーワード検索＝`https://www.hotpepper.jp/CSP/psh010/doBasic?FWT=<語>&SA=SA72&MA=<Y955|Y956>`。
  既定で落ちるもの: `SA`（都道府県）と `MA`（市区）を渡さないと全国から拾う。打ち消し＝両方を必ず付ける。
  ジャンル別の市内一覧＝`https://www.hotpepper.jp/SA72/Y955/G013/`（G013=ラーメン・G007=中華・G005=洋食・G006=イタリアン/フレンチ）。
- **松江観光協会の画像は `https://data.pc-egg.com/blobs/<id>` から `/large?size=N` を削ると原寸**（1600〜5760px）。
  ただし店によっては原寸でも285×221しかない。**観光「スポット」側のページ**にグルメ側より大きい画像があることがある。
- **まいぷれ松江**（`matsue.mypl.net`）はブラウザ相当の UA と Accept-Language が要る（さもないと403）。
  店舗ページのメニュー欄の画像は `p=s3-img-origin03` の `_menu.jpg` が原寸1600px。
  記事本文の画像は `&s=1600_1600` で原寸が出るが、元が740pxなら増えない（`s=3000_3000` だと逆に100pxに縮む仕様）。
- **アメーバブログの画像は `?caw=800` を外すと原寸**、**まっぷるは `-640x426` 等の接尾辞を外すと原寸**、
  **るるぶも接尾辞を外すと原寸**。個人ブログにドメインを絞って検索すると1080px級の訪問記が出る。
- **出雲観光協会の「出雲そば」ジャンル一覧**＝`https://www.izumo-kankou.gr.jp/?p=5728&ctg=出雲そば`（22軒・電話・営業時間つき）。
- **松江観光協会の飲食店一覧**＝`https://www.kankou-matsue.jp/gourmet/list`。

### 写真源としての落とし穴
- **ホットペッパーの無料掲載ページ（`psi010F0` 形式）の `IMGH/..._238.jpg` は、その店の写真ではなく近隣店の広告枠。**
  原寸は1280pxで大きさの条件を満たすので、サイズだけ見て採ると取り違える。
  **複数の店に3回以上出てくる画像は広告として捨てる**（島根では十数点が共通して出た）。
- **HAMONI**（`hamoni.jp`）の画像は Cloudflare R2 の署名付きURLで失効するため、恒久URLとして使えない
  （電話番号・住所・Instagram の ID を取る一次情報としては有用）。
- **店が自分の写真に自分の屋号を入れているもの（献上そば羽根屋・喜多縁）は採用してよい。**
  除外するのは「**媒体名・番組名**の透かし」＝第三者の媒体が焼き込んだもの。
- **サイトに「写真の無断転載を禁止」と書いてあることは、除外の理由にならない**（B-686）。
  判定は「禁止と書いてあるか」ではなく「権利者から個別の申し入れがあったか」。
