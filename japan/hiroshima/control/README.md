## 2. 章の構成

**広島市は8章**。お好み焼き・鉄板焼き／牡蠣・瀬戸内の魚・あなご／居酒屋・郷土料理・地酒（流川・薬研堀）／広島つけ麺・ラーメン・中華そば／寿司・和食・割烹／焼肉・ホルモン・広島牛／イタリアン・フレンチ・各国料理／喫茶・カフェ・甘味。

8章に必要な2色（`brown` `#8a5a2b`／`green` `#3f7d20`）は岡山市のときに `build_html.py` と `map_build.py` へ足してある。**今回はそれを使い回した。追加の作業は不要だった。**

**福山市は6章**。寿司・和食・鞆の浦の魚／尾道系の中華そば・ラーメン／お好み焼き・府中焼き・麺類／居酒屋・郷土料理・地酒／洋食・イタリアン・各国料理／喫茶・カフェ・甘味。

## 3. ホットペッパーの地域コード（当方が実際に開いて 200 を確認）

## 4. 地図の拡大図（INSETS・`map_build.py`）

**122店の座標を実測してから枠を決めた。最初に当てずっぽうで置いた枠は使い物にならなかった**（広島市の1枠目が33店、4枠目が65店を拾い、「拡大図」になっていなかった）。

- 広島市: ①流川・薬研堀・胡町（17店） ②八丁堀・本通り・袋町・紙屋町（12店） ③広島駅前・エキニシ・的場町（9店） ④大手町・十日市・本川町（15店）。重複を除いて53店を拾い、残る19店は全域図で見る。
- 福山市: ①福山駅前・元町・三之丸・霞町・伏見町・船町（18店） ②鞆の浦（8店） ③松永・南松永（3店） ④神辺・道上（4店）。

**あわせて `map_build.py` を2か所直した**（どちらも広島市で発覚した一般の不具合で、他の県にも効く）。

1. **拡大図のズーム上限を 16 から 18 へ。** ズームは「1800x2200px に収まる最大」を自動で選ぶので、**枠を実測で絞るほど出来上がりの画素数が小さくなる**。広島市の流川の枠は 256x339px しかなく、本文幅106mm に載せると 61dpi でぼやけて読めなかった。上限であって固定値ではないので、枠の大きい市はこれまでどおり自動で下がる。
2. **地図の保存を PNG から JPEG(quality=88・色間引きなし) へ。** 1 でぶんの画素数が増えたため。256色への減色も試したが、**地色に palette が割り当てられてピンの色が濁る**（赤が茶色、緑が暗い黄土色）ので採らなかった。JPEG はピンの色も文字も保ったまま PNG の54%。ファイル名は `map_<市>.json` 経由で `build_html.py` に渡るので、**既存の冊は作り直さないかぎり影響を受けない。**

## 6. 写真

候補は**広島市519本・福山市397本**。そこから**全数を目で見て**1店1枚を選定。

採用の出どころ:

- 広島市 … ホットペッパー58／各店の公式サイト6／ペコマガ5／ひろしま観光ナビ Dive! Hiroshima 1／ぐるなび1／個人ブログ1
- 福山市 … ホットペッパーが大半、ほかに きびナビ（`fuuraiki.com`）・備後とことこ（`media.bintoco.com`）・鞆物語（`tomonoura.life`）・VISIT鞆の浦（`visittomonoura.com`）・各店の公式サイト・個人ブログ

**目視で外したもの（広島16枚・福山8枚）**: 人物が主役の写真（五エ門の客と焼き手4枚・サコイ食堂の来店客2枚・ちんちくりんの焼き手と客2枚・みっちゃん総本店の焼き手2枚・とみや別館の店内1枚・白糖の女性1枚・小魚阿も珍の調理人2枚・鞆膳の調理人1枚）、店のロゴを重ねた合成バナー（くじら屋1枚）、外観だけのもの（我が家・かき傳・ルーエぶらじる・御舟宿いろは）、店先の置物と木彫りの看板（おばんざい山ろく2枚）、飲み物単体（三茶1枚）。除外の理由は `control/photo_exclude_<市>.json` に1枚ずつ日本語で書いてある。

### この回で見つけた取得先

- **きびナビ `https://fuuraiki.com/`** … 福山・井笠・備後地方のグルメ記事が多数。住所・電話・営業時間と**長辺1200px以上**の写真が揃う。福山のラーメンの章はここが主要な供給源になった。
- **備後とことこ `https://media.bintoco.com/`** … 福山の地域メディア。
- **鞆物語 `https://tomonoura.life/`** と **VISIT鞆の浦 `https://visittomonoura.com/`**（日本遺産鞆の浦魅力発信協議会・事務局は福山市文化振興課）… 鞆の浦の店はこの2つで写真と営業情報が揃う。**鞆の浦@cafe・とうろどう・深津屋・千とせ・御舟宿いろは は、ここが無ければ写真0本だった。**
- **ホットペッパーの店別ドリンクページ `https://www.hotpepper.jp/<店ID>/drink/`** … 地酒の銘柄が県名付きで全部載る。「地酒あり」の表示だけに頼らず銘柄を書きたいときに効く。
- **`curl` で DuckDuckGo の HTML 版（`https://html.duckduckgo.com/html/?q=…`）と Yahoo!検索（`https://search.yahoo.co.jp/search?p=…`）が素直に引ける。** WebSearch の枠を使わずに地元の情報へ辿れる。DuckDuckGo は連打すると202のチャレンジページを返すので間隔が要る。

### 落とし穴

- **ホットペッパーで掲載契約の無い店の `/photo/` には、他店の画像しか並ばない**（`alt` 属性で切り分ける）。広島の薬研堀 八昌、福山の千とせ・御舟宿いろは がこれに当たった。
- **`_480` を削れば原寸、とは限らない。「原寸が480px」の店が一定数ある。** 必ず落として `print(im.size)` で実測すること。福山の遊酒蔵 純は26枚すべて480pxで、全滅した。

## 10. 申し送り

- **広島市に尾道系の中華そばの店は1軒も入っていない。** 写真の条件（長辺900px以上）を満たす尾道系の店が広島市内で見つからなかった。福山市の章には尾道系が5店ある。
- **鞆物語（`tomonoura.life`）の各ページには「掲載内容の商用および営業目的での使用は禁止」の注記がある。** このガイドは個人用で商用ではないため採用したが、**もし販売や広告に使うなら先方への確認が要る。** 福山の章で鞆物語由来の写真を使っているのは 民芸茶処 深津屋・茶房とうろどう・活魚料理 千とせ・御舟宿いろは の4店。
- **ドブロブニク（欧州の冊）の Pizzeria Tabasco だけ、全4,951店のうち唯一座標が無い。** 今回 Photon・Nominatim・Overpass を当たったが OSM に Hvarska 通りのデータが無く解けなかった（詳細＝ai-memory の `topics/common/notes/blocked_routes.md` BR-112）。**今回作った広島市72店・福山市50店は122店とも解けている。**
- **福山市の船町（居酒屋）と松永（居酒屋）は空いている。** 船町の遊酒蔵 純は広島地酒7銘柄を置く良店だが写真が全点480px、松永の候補2店は焼き鳥中心で地元色が薄かった。
- **「福つまみ」は福山市の取り組みで、ねぶと・ちいちいいか・くわい・ガス天・鯛ちくわの5つを指す。** 和彩酒膳 照月の掲載ページに店自身の言葉で定義があり、郷土料理の章の軸になった。
- **保命酒とくわいを「料理として」出す店は、福山市の和食の掲載76店を全件走査しても見つからなかった。** 瀬戸内料理たんとが出しているのは保命酒梅酒800円とくわい焼酎600円で、どちらも飲み物。JSON にもその旨を書いてある。
