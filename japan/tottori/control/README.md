## 写真源として使えない先（調べ直さないこと）

- `tabelog.com` / `tblg.k-img.com`（食べログ＝利用者の投稿写真）
- `images.miil.me`（ホットペッパーの口コミ欄の利用者投稿）
- `imgfp.hotp.jp` は一覧の `_238`・`_480` が既定だが、**サイズ指定の接尾辞を削ると原寸 1000〜1280px が取れる**。
  ただし**全店のページに同じ13点ほどの広告画像が混ざる**ので、複数店に3回以上出る画像は広告として捨てる。
- `cdn-mapple.net`（まっぷる）は 640×480 が上限＝写真源にならない（住所・営業時間の出典としては有用）。
- `makeshop-multi-images.akamaized.net` の「とっとり市」出店者の商品画像は **「©とっとり市」の透かし入り**。
- `localcuisine-japan.com` は料理の挿絵が **AI 生成イラスト**（実写のみの規則に反する）。
- `sun-in-compass.com` は店名で引くと**不動産物件の写真**が返る（店と無関係）。
- ~~`tottorizumu.com` は記事末尾に「※写真の無断掲載・使用を禁止します」の明示あり＝出典リンクのみ可。~~
  **【2026-10-05 訂正・ユーザー判断「採用して」】ユーザーの指示により採用した。**2026-07-10 の恒久方針（成果物は個人利用。ブログ・観光サイト由来の写真の利用は著作権を気にしなくてよい。出典明記は継続）を適用する。採用した3枚＝鳥取牛骨麺 藤喜（IMG_0378）・らーめんひんま（IMG_2193）・粋な中華蕎麦 みらい（IMG_1290）。`photo_pick_tottori.json` の `src` に「地域情報サイト「とっとりずむ」（tottorizumu.com）より引用」と明記済み。**以後の県でも、同種の「無断掲載禁止」の明示があるだけのサイトは、この方針により写真源として使ってよい**（実際に権利者から申し入れがあった場合は個別に外す）。
- `na-na.media` の **`spice_` で始まるファイル名の系列**は日本海テレビの番組映像のキャプチャで、
  画面上部に番組名のテロップが焼き込まれている。**同じホストでも自社撮影の記事には透かしが無い。**
- `stat.ameba.jp` は多数の個人ブログが共用する CDN なので、**ホストではなくブログ単位**で透かしを判定する
  （`ameblo.jp/sanin-department-store` は「山陰百貨店」の透かし入り）。
