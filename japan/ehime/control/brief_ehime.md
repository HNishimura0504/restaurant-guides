## 3. 営業している根拠（`reason` に必ず書く）

次のどれかを、**日付つきで**書いてください。

1. 公式サイト・公式SNSの**2025〜2026年の更新**（投稿日・更新日を書く）
2. ホットペッパーのネット予約カレンダーが先の日付まで「即予約可」になっている（確認した期間を書く）
3. 口コミの最近の日付（Yahoo!マップ等。日付を書く）

**【重要】根拠が「開店の告知記事」だけの店は、`店名 + 閉店` で1回検索し、閉店の報が無いことを確かめてから採用してください。** 開店記事は開店日の証拠であって、今日営業している証拠ではありません（実例＝開店3か月で閉じた店が2件あり、どちらも載せかけました）。

**グルメサイトに掲載が残っていることは、営業の証拠になりません。**

## 4. 写真の条件（ここを外すと作り直しになります）

- **大きさの下限＝長辺900px以上。**「長辺」です。短辺は問いません。
  - 合格の例: 1200×800・2880×800・1060×600・1280×853
  - 不合格の例: 640×480・699×446・825×550
- **食べログ（`tabelog.com` / `tblg.k-img.com`）は使わない。** 利用者の投稿写真なので転載できません。
- **媒体名の透かし（ウォーターマーク）が焼き込まれた画像は使わない。** 透かしは「1枚の事情」ではなく「配信元の方針」なので、1枚見つけたらそのサイト全体を避けてください。
  **「たぶん無い」で済ませず、実際に右下を切り出して目で見てください**:

```bash
curl -sL -A "Mozilla/5.0" "<画像URL>" -o /tmp/x.jpg
python3 -c "
from PIL import Image
im=Image.open('/tmp/x.jpg'); w,h=im.size; print(im.size)
im.crop((int(w*0.40),int(h*0.70),w,h)).save('/tmp/corner.png')"
```

そのうえで `/tmp/corner.png` を Read ツールで開いて目で見る。

- **写真が1枚も取れない店は採用しないでください。**（カードが作れません）

## 5. URL の扱い

- `website` と `sources[].url` は、**実際に開いたページの URL をそのまま**書く。
  **店名のローマ字からドメインを推測しない**（過去に3件とも誤り、別会社・存在しないドメイン・別県の旅館に当たりました）。
- ホットペッパーの画像は `https://imgfp.hotp.jp/<以下は店ごとに違う>` の形です（URL-CHECK-SKIP＝雛形）。`_480` を外すと大きくなることがありますが、**必ず大きさを測って確かめてください**（外しても変わらない場合があります）。

```bash
python3 -c "
from PIL import Image; import io, urllib.request
r=urllib.request.Request('<URL>', headers={'User-Agent':'Mozilla/5.0'})
print(Image.open(io.BytesIO(urllib.request.urlopen(r).read())).size)"
```

- 契約していない店のページの `/photo/` には**他店の写真が混ざります。** `alt` 属性を見て店名が一致することを確かめてください。

## 7. 【香川県（2026-11-03）で実測した取得経路・愛媛でもまず試すもの】

**【いちばん大事。香川でこれを踏み外して作り直しになりました】「原寸が取れること」と「使ってよいこと」は別の問いです。**
**画像の大きさを測ったら、同じ回にその媒体の著作権・利用条件のページを開いてください。**
**新聞社・放送局・自治体が運営する媒体は、画像が大きく取れても転載が許諾制のことが多い。**
実例＝COOL KAGAWA（四国新聞社）は接頭辞を外すと1200pxの原寸が取れますが、
`https://www.shikoku-np.co.jp/info/copyright.htm` が**「他サイトへの転載は原則不可」「出版物・広告での使用は申請と使用料が必要」**と明記していました。
**愛媛新聞（`www.ehime-np.co.jp`）も同じ可能性が高いので、画像を使う前に著作権のページを必ず開いてください。**
**フッターに「無断転載を禁じます」と明記している店の公式サイトも同じ**（実例＝`www.ooshima-udon.jp`・`www.nakamura-udon.jp`）。

**写真源の1位はホットペッパーグルメ**（徳島・香川とも同じ結論）。`_480` を外した裸のURLが原寸で958〜1280px。
**ただし「裸でも853px前後しか返さない店」が混ざるので、店単位ではなく1枚ずつ実測してください。**
別経路の原寸URLは `imgfp.hotp.jp/IMGH/<P番号の末尾4桁を2桁ずつ>/<P番号>/<P番号>.jpg`（**先頭4桁ではなく末尾4桁**）。

**`/photo/` の構造（香川での実測。愛媛も同じはず）**:
`<li class="photo-list jsc-photo-list" … data-src="…" data-genre="…" data-alt="…" data-title="…" data-description="…">` で、
**`<img src>` が無く `data-src` に入っています。** 属性が改行をまたぐので `re.DOTALL` 必須。
`data-genre="post"`（`images.miil.me`＝利用者投稿）は必ず除外。
`data-title` と `data-description` に品名・価格・説明文がそのまま入るので、`sig` と `desc` の材料になります。
**`data-genre="appearance"` は「外観」という意味ではありません**（店内の席も料理も混ざる）。
**外観は `data-alt` が「〜の外観写真N」のもの、または `data-title` が空の appearance に紛れています。** 1枚ずつ目で見て分けてください。

**一覧ページの店名・住所はHTMLに入っていません（JSで描画）。** 先頭の `<script type="application/ld+json">` の `ItemList` に
1ページ20件の店舗URLが順序つきで入るので、そこから拾って店舗ページを個別に取ります。
一覧の店名を `class="shopDetailStoreName"` だけで拾うと**広告枠（`shopDetailStoreName dokoara`）を取りこぼす**ので `shopDetailStoreName[^"]*` にしてください。

**店舗ページ本文のJSON-LDに `telephone` と `latitude`/`longitude` が平文で入ります。**
**電話は `https://www.hotpepper.jp/<店ID>/tel/` にも平文であります。**

**営業の根拠として最強なのは店舗ページ（または `/food/`）本文のネット予約カレンダー。**
`re.sub(r'<[^>]+>','',html)` でタグを剥がしてから `2026年11月` を探すと `1TEL2◎3◎4休…` と3か月ぶんが丸ごと取れます
（◎＝即予約可／□＝リクエスト／休＝定休日）。**`/<店ID>/yoyaku/` は400を返す**ので本文から拾ってください。
**店舗ページの「こだわり」欄の画像（`lb_rkodawari_` が付くもの）は、裸URLでも320〜483pxしか返しません。** `/photo/` 由来の画像だけが原寸になります。

**Yahoo!検索の癖**: `-A "Mozilla/5.0"` だけだと**中身の空な17KBの結果ページ**が返り、ヒット0と誤判定します。
**完全なChromeのUA文字列**（`Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Safari/537.36`）と
`Accept-Language: ja` を付けると正常な結果（25万〜100万バイト）が返ります。**応答が25KB未満なら6〜8秒あけて再試行。**

**Yahoo!マップの店舗ページが営業確認で最速**: `https://map.yahoo.co.jp/v3/place/<ID>`（URL-CHECK-SKIP＝雛形。**デスクトップUA必須**）。
HTML中のNext.jsのペイロードが `\"key\":\"value\"` の形で埋まっているので **`\"` を `"` に置換してから**正規表現をかけます。
使えるキー＝`shareText`（店名・業態・口コミ件数・住所・電話を1行で）／`days`（**曜日別の営業時間と `holidaysStatus`。1が定休日。散文の `businessHoursText` より信頼できる**）／`budget`／`officialUrl`／口コミ本文と `postedAt`。
**`postedAt` は「2026年9月16日」という日本語表記なので文字列ソートでは最新が取れません**（数値に直して比較）。
IDは Yahoo!検索の結果HTMLから `map.yahoo.co.jp/v3/place/([A-Za-z0-9_-]+)` で拾います。
**`https://map.yahoo.co.jp/search?q=` は4KBの空のJSシェル、`/v3/search?q=` は404**で、どちらも使えません。

**WordPress のサイトでは、画像の寸法を1リクエストで全部取れます**:
`https://<ドメイン>/wp-json/wp/v2/media?per_page=100&_fields=source_url,media_details`（`media_details.width/height` が返る）。
**既定で落ちるもの: `per_page` の既定は10。`_fields` を付けないと本文まで返って応答が肥大します。**

**公式サイトの原寸の取り方（既知の型）**: Jimdo（`image.jimcdn.com`）は `/transf/<何か>/` を `/transf/none/` に置換／
グーペ（`r.goope.jp`）はサムネイルの `_l` を外す／Wix（`static.wixstatic.com`）は `.jpg` 以降の変換パラメータを全部削る／
レストランボード（`cdn.r-corona.jp`）は `_wNNNhNNN` `_sq_wNNNhNNN` を外す／
`localplace.jp` 型の「公式サイト」はギャラリーが**全点600×400固定**なので**測らずに飛ばして構いません**。

**使えなかった経路（四国3県で共通）**: 楽天ぐるなび（`r.gnavi.co.jp`・検索も店舗ページも503）／ヒトサラ（403）／
AutoReserve（Cloudflare 403）／食べログ（403・方針でも使用禁止）／Retty（406）／`hamoni.jp`（画像が利用者のSNS投稿）／`ekiten.jp`（店舗写真がページに出ない）。

**ドメイン推測の罠**: 店名のローマ字からドメインを当てにいくと外れます（香川では `sakaedaudon.jp` が店と無関係のアフィリエイトサイトでした）。
`http://` のURLは Python の `urllib` だとプロキシを通らず名前解決に失敗するので **`curl -sL` を使ってください。**

- **じゃこ天**＝ほたるじゃこ等の小魚を骨ごとすり身にして揚げる。温めて大根おろしで。
- **鍋焼きうどん**＝アルミ鍋の甘い出汁。**松山では昼から食べる定番**で、朝から開く専門店がある。
- **松山鮨（まつやまずし）**＝瀬戸内の魚とおぼろを混ぜた箱寿司。祝いの席の料理。
- **五色そうめん**、**伊予牛 絹の味**、**媛っこ地鶏**、**鯛そうめん**。
- **伊予の地酒**＝石鎚（西条）・賀儀屋（西条）・雪雀（松前）・媛囃子・栄光・山丹正宗。
- **柑橘**＝温州みかん・伊予柑・紅まどんな・甘平・せとか。**果汁の蛇口**を置く店がある。
- **菓子**＝**タルト**（あんを巻いたロールケーキ状の和菓子。果物のタルトではない）・**坊っちゃん団子**・**母恵夢（ぽえむ）**・**labo（ラボ）**・**一六本舗**・**六時屋**。

### 今治市（人口 14.2万・約45店が目安）

タオルと造船の町。**しまなみ海道**の四国側の起点。

- **今治焼き鳥**＝**串に刺さない。** 鉄板に載せて上から鉄の重しで押さえ、短時間で焼く。**皮**（かりかりに焼いた鶏皮）が看板の店が多い。**この章を独立させるほど厚い。**
- **焼豚玉子飯（やきぶたたまごめし）**＝ご飯に焼豚を敷き、半熟の目玉焼きを載せ、甘辛いタレをかける。中華料理店のまかないが発祥で、市内の中華・ラーメン店の定番。
- **せんざんき**＝鶏の唐揚げ。今治が発祥とされる。
- **来島海峡（くるしまかいきょう）の鯛**＝潮が速く身が締まる。刺身・鯛めし・鯛そうめん。
- **法楽焼（ほうらくやき）**＝焼いた石の上に魚介を載せて蒸し焼きにする漁師料理。
- **しまなみの柑橘**（大三島のレモン・伯方島のみかん）、**伯方の塩**。
- **場所のかたまり**: ①**今治駅前（JR今治駅）** ②**本町・常盤町・片原町**（銀座商店街の一帯。夜の店と焼き鳥屋） ③**今治港・みなと交流センター** ④**しまなみ海道**＝大島・伯方島・大三島（車か自転車） ⑤**郊外**＝波方（なみかた）・菊間・玉川。
- **人口14.2万で店の総数が少ないので、隣接市町で補ってよい。** 補った店には JSON に `"tags": ["rinsetsu"]` を入れ、`desc` の冒頭に「（西条市）」のように市町名を書く。
  補ってよいのは **西条市・新居浜市・上島町・東温市・松前町・砥部町**（ただし松山市の章と重ならないこと）。
- **島の店は昼だけ・不定休が多い。** 営業の根拠を特に厳しく取ってください。
