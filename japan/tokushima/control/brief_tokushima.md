## 3. 営業している根拠（`reason` に必ず書く）

次のどれかを、**日付つきで**書いてください。

1. 公式サイト・公式SNSの**2025〜2026年の更新**（投稿日・更新日を書く）
2. ホットペッパーのネット予約カレンダーが先の日付まで「即予約可」になっている（確認した期間を書く）
3. 口コミの最近の日付（Yahoo!マップ等。日付を書く）

**【重要】根拠が「開店の告知記事」だけの店は、`店名 + 閉店` で1回検索し、閉店の報が無いことを確かめてから採用してください。** 開店記事は開店日の証拠であって、今日営業している証拠ではありません（実例＝開店3か月で閉じた店が2件あり、どちらも載せかけました）。

**グルメサイトに掲載が残っていることは、営業の証拠になりません。**

## 4. 写真の条件（ここを外すと作り直しになります）

- **大きさの下限＝長辺900px以上。**「長辺」です。短辺は問いません。
  - 合格の例: 1200×800・2880×800・1060×600・1280×853
  - 不合格の例: 640×480・699×446・825×550
- **食べログ（`tabelog.com` / `tblg.k-img.com`）は使わない。** 利用者の投稿写真なので転載できません。
- **媒体名の透かし（ウォーターマーク）が焼き込まれた画像は使わない。** 透かしは「1枚の事情」ではなく「配信元の方針」なので、1枚見つけたらそのサイト全体を避けてください。
  **「たぶん無い」で済ませず、実際に右下を切り出して目で見てください**:

```bash
curl -sL -A "Mozilla/5.0" "<画像URL>" -o /tmp/x.jpg
python3 -c "
from PIL import Image
im=Image.open('/tmp/x.jpg'); w,h=im.size; print(im.size)
im.crop((int(w*0.40),int(h*0.70),w,h)).save('/tmp/corner.png')"
```

そのうえで `/tmp/corner.png` を Read ツールで開いて目で見る。

- **写真が1枚も取れない店は採用しないでください。**（カードが作れません）

## 5. URL の扱い

- `website` と `sources[].url` は、**実際に開いたページの URL をそのまま**書く。
  **店名のローマ字からドメインを推測しない**（過去に3件とも誤り、別会社・存在しないドメイン・別県の旅館に当たりました）。
- ホットペッパーの画像は `https://imgfp.hotp.jp/<以下は店ごとに違う>` の形です（URL-CHECK-SKIP＝雛形）。`_480` を外すと大きくなることがありますが、**必ず大きさを測って確かめてください**（外しても変わらない場合があります）。

```bash
python3 -c "
from PIL import Image; import io, urllib.request
r=urllib.request.Request('<URL>', headers={'User-Agent':'Mozilla/5.0'})
print(Image.open(io.BytesIO(urllib.request.urlopen(r).read())).size)"
```

- 契約していない店のページの `/photo/` には**他店の写真が混ざります。** `alt` 属性を見て店名が一致することを確かめてください。

## 7. 【山口県で実測した取得経路・徳島でもまず試すもの】

### 写真源の歩留まり（山口県での実測順）

1. **楽天ぐるなび**がいちばん歩留まりがよい。店のページの `/photo/` を開き、サムネイルの `t_` を `s_`（1280px級）に替える。

```
https://r.gnavi.co.jp/<12桁のID>/photo/
```

2. **地元のウェブマガジン・タウン情報サイト**。山口県では `yamaguchi-san.com` が1000〜1200pxで透かし無しだった。
   **徳島県で同じ役を果たすサイトを最初に1つ探してください**（見つけたら報告に書く。次の担当が使います）。
3. **号外NET の市別**（山口県では下関市版が1記事10〜17枚・全部1280px級・透かし無しで最良だった）。

```
https://tokushima.goguynet.jp/
```

4. **店の公式サイト**。CMS（`cdn.goope.jp`・`sb2-cms.com` 等）のCDNもここに含む。
5. **ホットペッパー**は、山口県では `_480`（480px）止まりで `_480` を外すのも `_690`／`_820`／`_1000` もすべて404だった。
   **ただし広島・岡山では裸のURLが原寸（1280×960級）で返った。県ごとに違うので、徳島では1枚測ってから判断してください。**

### 写真源として使ってはいけないもの（2026-10-25 の山口県で確定）

1. **食べログ**（利用者の投稿写真）
2. **個人ブログ**（アメブロ `stat.ameba.jp`・ライブドア等。撮影者が店でも媒体でもない）
3. **透かしの焼き込まれたサイト**

**よいもの＝店・公式の観光／商店街／自治体のサイト・編集部のある媒体。**
予約サービス（AutoReserve 等）は店舗提供写真だが、同じ店に編集部のある媒体の写真があるならそちらを採る。

### 座標が町名どまりのときの逃げ道

**Yahoo!マップの店舗ページから拾えます**（`toLat=`／`toLon=`）。デスクトップのUAが要ります。

```
curl -sL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64)" "https://map.yahoo.co.jp/v3/place/<店のID>" -o /tmp/m.html
```
既定で落ちるもの: ①`-A` を付けないと携帯向けの版が返り座標が本文に出ない ②`-L` を付けないと 301 で止まる ③本文の `&` は `&amp;` の実体参照。

### 営業の確認は3通り取る（2026-10-27 に閉店した店を載せかけた）

**予約サイト・掲載サイトが生きていることは、店が開いていることの根拠になりません。**（掲載は閉店後も消えるまで残る）
①空白ありなしの両方で `店名 閉店` を検索 ②**公式SNSのアカウント名そのもの**を見る（閉店した店は「旧〇〇／現在は△△」に変える）③移転・リニューアルの検索。

## 8. 徳島県の下調べ（これを前提に探してください）

### 徳島市（人口 25.2万・約50店）

- **徳島ラーメン**＝豚骨醤油の「茶系」が主流。甘辛く煮た豚バラと**生卵**を載せるのが徳島流。ほかに「黄系」「白系」がある。**この県でいちばん厚い章になります。**
- **阿波尾鶏（あわおどり）**＝県の地鶏。全国の地鶏で出荷量1位。焼き鳥・水炊き・たたき。
- **鳴門鯛・鳴門わかめ**＝鳴門海峡の激しい潮で身が締まる。
- **ハモ**＝徳島の夏の魚。
- **すだち**＝全国生産のほぼ全部が徳島産。
- **フィッシュカツ**＝魚のすり身にカレー粉を混ぜて揚げた県民食。惣菜店・スーパーの定番。
- **たらいうどん**＝徳島市の北西（土成・御所）が本場。大きなたらいで供する。
- **半田そうめん**＝つるぎ町半田。麺が太い。
- **秋田町（あきたまち）**＝四国最大級の歓楽街。徳島駅から南へ徒歩10分。新町川のそば。
- **眉山（びざん）・両国橋・新町橋・ひょうたん島**＝中心部の目印。
- **阿波おどり**＝8月。会館は年中演舞あり。

### 阿南市（人口 6.9万・約45店）

- **太平洋に面した港町**。橘湾・蒲生田岬（かもだみさき）・伊島。**「光のまち」**（青色発光ダイオードの日亜化学工業の本社がある）。
- **阿南のたけのこ**＝春の名物。
- **伊勢えび・ハモ・わかめ・ちりめん**＝橘湾・椿泊の漁。
- **JR牟岐線**が南北に走る。中心は**阿南駅**と**富岡（とみおか）の商店街**。
- **人口6.9万で45店は厳しい見込みです。** 足りない分は**隣接市町**（小松島市・那賀町・美波町・阿波市ではなく**南隣の美波町**と**北隣の小松島市**）から採り、
  **`tags` に `"rinsetsu"` を入れて**ください。**どの市町から採ったかを `area` に必ず書く**こと。
