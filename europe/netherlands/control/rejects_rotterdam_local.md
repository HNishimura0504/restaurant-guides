# ロッテルダム・郷土料理（local）— 落とした候補

| 店名 | 理由 | URL |
|---|---|---|
| Stadsbrouwerij De Pelgrim（Delfshaven） | 営業中（2026年のイベント告知あり）だが、料理はナチョス・バーガー・ホットドッグ中心で郷土料理にあたらない（口コミの味の評価もバーガーに集中） | https://www.pelgrimbier.nl/proeflokaal ／ https://verkenrotterdam.nl/places/stadsbrouwerij-de-pelgrim-rotterdam-delfshaven/ |
| Captain's Cabin（Scheepvaartkwartier） | 水曜のスタンポットの夜は魅力だが、営業は月〜金のみ（週末休み）で週末に訪れる読者には合わない。第三者による味の評価も見つからず | https://www.captainscabin.nl/ ／ https://rotterdamspotted.com/en/dutch-food-rotterdam/ |
| Villa Kakelbont（Halvemaanpassage） | 2026年に再開した居間風カフェ。スタンポットと子ども用の遊びコーナー・子どもメニューありで子連れ向きだが、開店紹介記事ばかりで第三者が味に触れた文が無い（次回再調査の候補） | https://www.uitagendarotterdam.nl/alle-artikelen/villa-kakelbont-is-als-vintage-huiskamercafe-terug-in-rotterdam/ ／ https://www.entreemagazine.nl/culinair-chefs/stamppot-snert-en-hachee-deze-13-restaurants-serveren-hollandse-pot |
| Vader Kleinjan（Oude Haven） | スタンポットは冬の期間限定（日〜火、2025年2月1日で終了の告知）で、通常はスペアリブ中心のカフェ。第三者による味の評価は見つからず | https://vaderkleinjan.nl/hollandsche-stampot-eten-in-rotterdam/ |
| De Matroos en het Meisje（Katendrecht・Deliplein） | 料理はピスタチオソースのパスタなど多国籍のおまかせコースで郷土料理ではない。口コミに「mediocre」「too salty」「portions really small」の指摘もある | https://www.bartsboekje.com/de-matroos-en-het-meisje-rotterdam/ |
| Poffertjessalon Seth | 公式ドメイン poffertjessalonseth.nl がカジノのスパムサイトに乗っ取られており、閉店が疑われる。2025〜26年の営業中の証拠なし | https://www.poffertjessalonseth.nl/ |
| Broox（旧 Dutch Diner、Meent 20） | 口コミにポッフェルチェ・パンケーキの味の評価はある一方、S1（「De porties waren meer dan royaal… ik kon niet alles opeten」）もある。公式サイトが503で、2025〜26年の営業中の証拠を得られなかった | https://verkenrotterdam.nl/places/broox-dutchdiner-rotterdam/ ／ https://www.brooxrotterdam.nl/ |
| Zeezout（Westerkade） | ミシュラン掲載の魚料理店だが、昼 €57.50〜の高級店で世界各地の料理の影響が強く、郷土料理枠や乳児連れには合わない | https://guide.michelin.com/us/en/zuid-holland/rotterdam/restaurant/zeezout ／ https://www.restaurantzeezout.nl/ |
| Jaffa（Witte de Withstraat） | カプサロンの有名店だが、2025年の試食で評論家が「Het is allemaal prima, maar niet uitzonderlijk… lijkt iets vlakker van smaak」と評価（S2）。カプサロンは El Aviva・Mimoza の2店で足りるため外した | https://www.uitagendarotterdam.nl/alle-artikelen/de-grote-uitagenda-kapsalontest/ |
| De Cocosnoot（Witte de Withstraat） | 同じ試食で味4つ星だが「de verschillen zijn minimaal」「sfeer… een beetje kil」と評価が控えめ。カプサロン枠が重複するため外した | https://www.uitagendarotterdam.nl/alle-artikelen/de-grote-uitagenda-kapsalontest/ |
| SnertTram（Oostplein 発） | 1969年製の路面電車でエルテンスープを食べながら市内を巡る企画（土日 14:30〜16:00）。冬季中心の催しで、5月に運行するかは未確認。レストランではない | https://www.uitagendarotterdam.nl/locaties/locatie/snerttram/ |
| Dudok（Meent） | アップルパイで有名なグランカフェ。郷土料理というよりカフェ・菓子の枠に入るため、このカテゴリーからは外した（別カテゴリーで検討を） | https://dudok.nl/ |
| Schmidt Zeevis／Fred Haring en Vis | 口コミで魚の味は好評だが、Matlingeweg（工業地帯）と Meyenhage（南部の住宅地）で中心部から遠く、トラムで回るのに向かない | https://verkenrotterdam.nl/places/schmidt-zeevis-rotterdam-b-v-rotterdam-netherlands/ ／ https://verkenrotterdam.nl/places/fred-haring-en-vis-rotterdam-zuid-holland/ |
| Vineum／Asian Glories（Bib Gourmand） | Bib Gourmand 掲載店だが、フランス・地中海料理と中国料理で郷土料理ではない | https://guide.michelin.com/us/en/zuid-holland/rotterdam/restaurants/bib-gourmand |
